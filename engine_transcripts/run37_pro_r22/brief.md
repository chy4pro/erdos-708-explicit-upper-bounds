# Target: Erdős's 2n conjecture for g(n), by the shared-prime incidence graph

Problem (Erdős–Surányi 1959, $100). For integers 1 < a_1 < … < a_n and any x ≥ 0, let g(A,x) be the least |B| over B ⊆ I = {x+1,…,x+a_n} with ∏A | ∏B, and g(n) = max over A, x. Erdős asked whether g(n) ≤ 2n. Known lower bound (2−o(1))n. Our published upper bound is g(n) ≤ 12n (Lean-verified) and 11n (refereed).

WHY THIS ROUTE AND NOT THE ONE WE PUBLISHED. Our 12n comes from a linear-programming relaxation plus a hinge inequality with an absolute threshold c, giving g(n) ≤ ⌈cn⌉ + 2n. That entire route is now PROVED to be capped: the hinge inequality fails for every c < 2 (explicit: r primes in [M, √2 M) with M > 2, all weights 1, m = p_{r−1}p_r, window centred at their product, gives left side C(r,2)(2−c) and right side r−1, so it fails once c < 2 − 2/r, and such prime clusters exist for every r). Hence the LP/hinge route cannot beat 4n and can never reach 2n. Also proved: the fractional cover value satisfies τ*/n → 2 on an explicit CRT sequence, so no (1+o(1))n comes from the LP either. The route below is combinatorial, uses no LP, and is NOT subject to that barrier — it already proves 2n on a large class.

## Proved machinery (verify each before use; all of it is available to you as a black box, but the campaign is worth nothing if you build on a misremembered statement)
Let Q be the set of primes dividing at least two distinct inputs, s = |Q|, W_s = Σ_{p∈Q} #{a ∈ A : p | a}. Let Γ be the bipartite graph on the n input vertices and the s shared-prime vertices with an edge (a,p) when p | a; let ν be its maximum matching, c its number of components (isolated input vertices included), and β = W_s − n − s + c its cycle rank.
P1 (anchor deficiency): for any anchor set S of interval elements, G ≤ |S| + Σ_p δ_p(S), with an exact nested prime-power shortage formula for δ_p.
P2: G ≤ Σ_a ω(a) − max_a ω(a) + 1.
P5/P6 (normalisation): common-divisor normalisation, and decomposition along disjoint demanded prime support; hence a minimal counterexample may be taken PRIMITIVE and CONNECTED.
P7 (matching bound): G ≤ n + W_s − ν. Proof sketch: match ν shared primes to distinct inputs; for each input a let t(a) be the product of its atoms at private primes (primes occurring in a only), and if a is matched to p multiply t(a) by the whole p-atom of a, giving f(a) | a; each nontrivial f(a) has a multiple in I; those ≤ n anchors kill every private-prime shortage and give δ_p ≤ c_p(1) − 1 at every matched shared prime, δ_p ≤ c_p(1) at unmatched ones; sum P1.
P8 (pseudoforest and cycle rank): with d = s − ν, G ≤ 2n − c + β + d and d ≤ max(0, β−1); componentwise d ≤ Σ_j max(0, β_j − 1). Hence: if every component of Γ has at most one cycle then G ≤ 2n; if Γ is a forest, G ≤ 2n − c; in general G ≤ 2n + 2β. The deficiency estimate uses that every shared prime has degree ≥ 2, so a set T of shared primes with neighbourhood N(T) satisfies 2|T| ≤ E_T = |T| + |N(T)| − c_T + β_T, whence |T| − |N(T)| ≤ β − 1, together with the König-type identity s − ν = max_T (|T| − |N(T)|).
P9: the incidence criterion may ignore inputs with at most two distinct prime factors (discard them first, then apply P8 to what remains).
P11: for a_n < 8n³, primes > 2n contribute at most two valuation units per input, leaving π(2n) = o(n) other rows.
Long intervals: if a_n ≥ 8n³ then 2n elements always suffice (proved, formalised). So ONLY the range a_n < 8n³ is open, and by P5/P6 only primitive connected instances matter.

## Refuted (do not re-derive)
F1: whole-input anchors do not always make the P1 bound ≤ 2n. F2: integer residual demands do NOT entail zero rounding loss. F3: low incidence cycle rank is NOT automatic in the critical range, and optimising the P9 certificate over subgraphs H does not always prove 2n; the same certificate also fails to give a uniform 3n. τ* ≤ (1+o(1))n is refuted (τ*/n → 2 on explicit CRT instances). Prefix-to-window injections are refuted by Hensley–Richards dense admissible windows (an interval can contain more integers free of small primes than [1,m] does) — Γ is a graph on the INPUTS and does not assume any such injection, so keep it that way.

## The crux
Primitive connected instances in 2n < a_n < 8n³ whose incidence graph Γ has LARGE cycle rank. P8 loses 2β there, so the whole question is whether the anchor construction can be improved when Γ has many independent cycles. Three concrete directions: (i) choose the anchor set S adaptively rather than from a matching — a cycle in Γ means several inputs share several primes, which should let ONE interval element serve several shared-prime demands at once, exactly the saving P7 fails to take; (ii) sharpen P1's shortage formula δ_p for primes of high degree, where the crude bound c_p(1) − 1 is wasteful; (iii) exploit that a high cycle rank forces many inputs to share primes, which by P2 bounds Σ ω(a) and constrains a_n from below — combine with the long-interval theorem to squeeze the open range.
