# Target: an absolute small threshold for the fractional hinge inequality (Erdős–Surányi function g(n))

Setting. Let P be a finite set of primes and z_p ∈ [0,1] weights. For an integer n ≥ 1 put S(n) = Σ_{p∈P} min(z_p v_p(n), 1), where v_p is the p-adic valuation. For m ≥ 1 and a window I = {x+1, …, x+m} (x ≥ 0), and a threshold c > 1, the HINGE INEQUALITY with threshold c is
   (H_c)   Σ_{k=1}^{m} (S(k) − c)^+  ≤  Σ_{b∈I} (S(b) − 1)^+ .
Why it matters (proved, you may use it): if (H_c) holds for all P, z, m, x then g(n) ≤ (c+16)·n for every n, where g(n) is the least g such that for every set of n integers 1<a_1<…<a_n and every x, some g of the integers x+1,…,x+a_n have product divisible by a_1⋯a_n (Erdős Problem #708; Erdős asked whether g(n) ≤ 2n). Currently proved: (H_65) for all weights, hence g(n) ≤ 81n. Your target is the smallest absolute c you can prove for ALL fractional weights:
