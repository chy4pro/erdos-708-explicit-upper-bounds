## Target (new modules under lean/proofenv/Erdos708/H17/Chain19/ — statement cards first, then proofs; nothing else touched)
T1 `primes_card_le (D : Problem) : D.primes.card ≤ D.n + ((Finset.range (Nat.sqrt D.m + 1)).filter Nat.Prime).card`.
   Proof: a prime p > √m dividing ∏A divides some a ∈ A; each a ≤ m has at most one prime factor > √m (two would multiply to > m); so the map from such primes to A is injective. The primes ≤ √m are counted by the filter.
T2 `pi_le (n : ℕ) : ((Finset.range (3*n+1)).filter Nat.Prime).card ≤ n + 1`.
   Proof: every prime other than 2, 3 is ≡ 1 or 5 (mod 6); the integers in [1,3n] that are ≡ 1 or 5 mod 6 number exactly n and include 1, which is not prime; add 2 and 3.
T3 `strict_rounding (D : Problem) : ∃ B, Covers D B ∧ (B.card : ℝ) < fractionalValue D + D.primes.card`.
   Proof: same vertex argument as `rounding` (adapt Proofs/Rounding); with F = fractional coordinates, |B| − τ* = Σ_F (1 − y_b) which is < |F| ≤ r when F ≠ ∅ and = 0 < r when F = ∅ (r ≥ 1 because A contains an integer ≥ 2). If adapting the existing proof is impossible in reasonable effort, prove instead the weaker `(B.card : ℝ) ≤ fractionalValue D + D.primes.card` (already there) and adjust T5 to `⌈c n⌉₊ + 2n + 1`; report which one you proved.
